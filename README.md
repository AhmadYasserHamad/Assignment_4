# Unsupervised Machine Learning Algorithms

## Overview
This repository contains implementations and experimental evaluations of foundational unsupervised machine learning algorithms. The codebase focuses on clustering techniques, dimensionality reduction, and neural network-based data reconstruction, emphasizing the mathematical and theoretical application of these models.

## Implemented Algorithms
- **K-Means Clustering:** Partitioning data into distinct groups based on feature similarity.
- **Gaussian Mixture Models (GMM):** Probabilistic models assuming that data points are generated from a mixture of finite Gaussian distributions.
- **Principal Component Analysis (PCA):** A dimensionality reduction technique used to project high-dimensional data into a lower-dimensional space while preserving core variance.
- **Autoencoders:** Neural network architectures designed for unsupervised representation learning and data compression.

## Project Structure
- `/Autoencoders`: Code and models for autoencoder implementations.
- `/GMM`: Implementations of Gaussian Mixture Models.
- `/K_Means`: Implementations of the K-Means clustering algorithm.
- `/Principle_Component_Analysis`: Dimensionality reduction scripts using PCA.
- `/Experiments`: Directory for isolated algorithmic testing.
- `Experiment1(full).ipynb` & `Experemnt2(full).ipynb`: Comprehensive Jupyter Notebooks detailing the experimental setup, execution, and results.
- `Evaluation_And_Analysis_Metrics.ipynb`: A dedicated notebook for evaluating model performance using standard clustering and reconstruction metrics.

## Requirements
- Python 3.8+
- Jupyter Notebook
